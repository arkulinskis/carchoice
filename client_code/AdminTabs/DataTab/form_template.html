Import car data

A spreadsheet saved as CSV (Excel: File, Save as, "CSV UTF-8"), one row per model. make and model are required; any column whose name isn't known yet becomes a new filter and column. Empty cells never wipe what's there.

Downloads

Edit everything in a spreadsheet and import it back: the export uses the same columns the importer reads.

Values the importer understands

  • Numbers: 27,500 / 27 500 / $27,500 / 6,1 all work. Metric units (mm, kg, km, L/100km, litres).
  • Several values (fuel, drive, gearbox, regions): separate with /, e.g. Hybrid/Plug-in hybrid.
  • Yes/no: yes, no, y, n, 1, 0, x.
  • Shortcuts: fuel P D H PH E, gearbox A M CVT DCT 1, regions NA EU UK AU AS ALL, status D = discontinued.
  • Features in one column: std 360 roof hud heatpump row3 man.
  • Known column names include Horsepower, MSRP, Transmission, Drivetrain, Seating, Curb weight, Euro NCAP.
